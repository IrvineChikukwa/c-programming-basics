# Area Calculator - Switch Menu

Calculates area of Circle, Square, Rectangle using menu-driven program.

## Features
- Menu based selection
- Uses switch-case
- Handles invalid input
- Formatted output to 2 decimals

## Concepts Used
- `switch` statement
- `scanf` / `printf`
- `const float`

## How to Run
```bash
gcc area_calculator.c -o area_calculator
./area_calculator

```
